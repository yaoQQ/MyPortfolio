# About

```tsx
// src/components/About.tsx
```

## 职责

"关于我"区块，展示个人照片（可选）、简介文字、联系信息。

## Props

| Prop | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 无 | — | — | 纯展示组件，文本硬编码在组件内 |

## 特性

- 左侧头像/占位 + 右侧文字布局
- 响应式：移动端切换为上下排列
- 支持亮色/暗色两种背景样式

## 代码要点

组件使用 Tailwind 网格布局：

```
grid grid-cols-1 md:grid-cols-2 gap-8
```
